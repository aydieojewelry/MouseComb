# For AI coding agents

This repo is built with AI agents (Claude Code, Antigravity, Codex, Cursor, …). Everything you need is in the repo.

1. Read [`CR/CR.md`](CR/CR.md): where things stand, the commands, the rules. Then say or follow **`>resume`** (defined there under **Help**).
2. Skim [`CR/META-RULES.md`](CR/META-RULES.md): how we work and how to reply.
3. Read `## Next` in [`CHANGELOG.md`](CHANGELOG.md) (the owner's intent) and the top entry of [`CR/DEVLOG.md`](CR/DEVLOG.md).
4. Read [`CR/APP_SPEC.md`](CR/APP_SPEC.md) only for the part you touch; cite `FEAT-xxx` / `DEC-xxx`.

Never commit to `main`, merge or release without the owner's approval, or skip a failing test. Step-by-step delivery: [`.claude/skills/steward/SKILL.md`](.claude/skills/steward/SKILL.md).
